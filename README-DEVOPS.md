# Prática DevOps — StoreManager

## Objetivo

Registrar os acordos de colaboração utilizados durante as práticas de DevOps, promovendo organização, rastreabilidade e qualidade nas alterações do projeto.

## Acordos de colaboração

1. **Commits padronizados:** utilizar Conventional Commits para descrever claramente o propósito de cada alteração.
2. **Revisão por Pull Request:** submeter alterações por meio de Pull Requests, permitindo revisão antes da integração à branch principal.
3. **Documentação atualizada:** manter a documentação pertinente ao projeto e às práticas atualizada, facilitando a compreensão e a reprodução dos procedimentos.

## Como verificar

Conferir os três acordos registrados neste documento e verificar se estão descritos de maneira clara e objetiva.

## Histórico da prática

Este documento será utilizado como parte das atividades práticas de DevOps, incluindo versionamento com Git, colaboração pelo GitHub e integração contínua.
